# 知识库大纲

> 这是一份持续维护的活文档：它定义"写什么、按什么逻辑写、写到什么程度"。新文章动笔前先到这里认领位置，写完回来更新状态。
>
> **进度**：首批条目已于 2026-10-24 全部入库（下表标"已写"并附文件名）。

## 使用规则

**标注图例**：

| 标注 | 含义 |
|------|------|
| 已写 | 文章已入库（附文件名） |
| 首批 | 与当前工作（舵机测试 / DMP / 动作库）直接相关，优先写 |
| 核心 | 该栏目的必要知识点，构成完整知识线 |
| 扩展 | 进阶或选读，有需要再写 |

**写作结构约定**（所有文章遵循同一知识观）：

1. **内核 → 规则与行为 → 抽象** 三段式：先理解"为什么这么做"（内核），由内核推导出可操作的规则与行为，最后给出更高层的抽象规则去便利之前繁琐的行为。定义力求简洁明了，晦涩处展开描述，句间保持逻辑衔接。
2. **原理类数学推理 → 数学基础；具体实现 → 对应栏目。** 例如：卡尔曼滤波的理论推导在数学基础，EKF 融合实战在感知与估计。两边互相引用而不重复。
3. **单一归属 + 术语跳转。** 每篇文章只属于一个栏目，跨栏目引用一律用 `[[术语]]` 跳转链接（术语表维护于 `.vitepress/glossary.ts`），不复制内容。

**知识主线**（八个栏目怎么串起来）：数学是工具 → 结构硬件是本体 → 感知让机器看世界 → 规划决策决定做什么 → 控制决定怎么动 → 软件中间件负责通信 → 系统仿真把一切拼起来验证。

## 1 数学基础

> 主线：变换的语言 → 弯曲空间上的微积分 → 带噪声的推断 → 求解方法。本栏目是全站的"理论仓库"，其他栏目遇到数学推理一律跳转到这里。

| 知识点 | 内容 | 标注 |
|--------|------|------|
| 线性代数的几何本质 | 矩阵=变换；特征值/SVD 的几何意义 | 核心 |
| 坐标变换与齐次矩阵 | T 矩阵、左乘/右乘（世界系 vs 机体系）直觉 | 已写（transform-homogeneous） |
| 旋转表示全家 | 欧拉角/轴角/矩阵/四元数的统一视角与选型规则 | 已写（rotation-representations） |
| 四元数 | S³ 双重覆盖、半角公式、SLERP、微分方程 | 已写（quaternion） |
| 李群李代数 SO(3)/SE(3) | 指数/对数映射、扰动模型、BCH、流形优化模式 | 已写（lie-groups） |
| 卡尔曼滤波理论 | Bayes 递推 → KF 五公式 → EKF/UKF（推导层） | 已写（kalman-filter） |
| 概率与高斯推断 | 贝叶斯、协方差、流形上的高斯 | 核心 |
| 数值优化 | 最小二乘、Gauss-Newton/LM、稀疏结构 | 核心 |
| 样条与插值理论 | B 样条、多项式插值的数学性质 | 扩展 |
| 粒子滤波与因子图 | 非线性/非高斯推断 | 扩展 |

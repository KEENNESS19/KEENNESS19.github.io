# 正逆运动学

**一句话定义：运动学 = 关节空间（各关节角）与笛卡尔空间（末端位姿）之间的映射，不含力与质量——正解唯一，逆解多解且可能无解。**

## 内核：为什么正逆解难度不对称

**正解（FK）**：从基座到末端是一串连杆变换的连乘（[[坐标变换与齐次矩阵]]的链式法则），给定关节角，末端位姿**必然唯一**——机械结构替你保证。

**逆解（IK）**：从末端位姿反解关节角 = 解一组非线性三角方程。三个结构性困难全都来自"反着解"：

1. **多解**：到达同一目标，肘上肘下、肩前肩后都行（n 自由度臂常有多组解）——解的选择要靠附加准则（离当前构型最近、避开障碍）；
2. **无解**：目标超出工作空间或在奇异面另一侧——这是几何事实，不是算法失败；
3. **奇异附近病态**：接近奇异位形时逆解的关节速度趋于无穷。

**雅可比**是两个空间之间的速度翻译官：$\dot{x} = J(q)\,\dot{q}$。它把"每秒关节转多少"翻译成"末端每秒动多少"。**奇异性 = J 降秩 = 某些笛卡尔方向失去产生速度的能力**（比如臂完全伸直时无法沿臂方向伸缩）。条件数 $\kappa(J)$ 度量接近奇异的程度——轨迹规划要保证全程 $\kappa$ 有界，这一条直接写进轨迹生成篇。

## 规则与行为

**DH 参数**：给连杆定四个参数（连杆长度 a、扭角 α、偏距 d、关节角 θ），使任何串联臂都能用统一的 4×4 变换表描述——FK 变成查表连乘。规则：**DH 表是机械图纸的数字化，必须在装配后实测校验**（零位对齐靠[[编码器]]标定与限位）。

**速度层规则（J 的用法）**：

1. **微分运动**：笛卡尔速度指令 → 关节速度，$\dot{q} = J^{-1}\dot{x}$——奇异附近 $J^{-1}$ 爆炸，实用中用阻尼最小二乘 $J^\top(JJ^\top + \lambda I)^{-1}$，λ 换取速度上限的稳定；
2. **静力映射**（对偶关系）：关节力矩 $\tau = J^\top F$——末端受力折算成各关节力矩，力控与重力补偿的基础；
3. **冗余臂**：自由度 > 6 时 $J$ 非方阵，用伪逆，解不唯一——**零空间**（$J\dot{q}_0 = 0$ 的关节运动不改变末端位姿）用来同时完成避障/避奇异等次要目标。

## 抽象：数值 IK——把解析法统一成优化问题

解析 IK 只对少数构型（球腕六轴臂）存在。数值 IK 的抽象是：**把"找到关节角"写成最小化问题**（位置误差 + 姿态误差 + 避障/限位正则项），用雅可比迭代求解。它的好处是"约束即正则项"——任何附加要求都变成代价函数里的一项，不必发明新算法。运动学库（KDL、Pinocchio、TRAC-IK）全部是这个抽象的实现。上层（轨迹生成、动作库）只见 `solve_ik(target, seed)` 一个函数——[[混合决策架构]]执行层里的每一次"到某位姿"，最终都落到这里。

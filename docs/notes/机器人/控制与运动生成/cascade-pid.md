# 级联 PID：从一条位置指令到三相电流的完整旅程

级联 PID 是把"位置 → 速度 → 力矩"的控制链拆成三个嵌套的反馈环，外环的输出是内环的指令。这句话作为定义是完整的，但作为理解是空的：为什么偏偏是三层？为什么不能一个环解决？为什么内环必须比外环快？为什么舵机振荡时第一反应是查内环？这些问题定义答不了，只有沿着一条指令在真实关节里走过的路，才能一个一个推出来。本篇就做这件事：从控制问题的物理形状出发推导出三环结构，再从结构推导出整定规则，最后回答系统层面的问题——这套结构的上限在哪里、什么时候不够用。

## 1. 问题的真实形状

先看被控对象到底是什么。机器人的一条运动指令到达关节时，中间隔着一条物理链条：

```
位置指令 → [控制器] → 电流指令 → [逆变器] → 相电流 → [磁场] → 力矩
        → [减速器] → 关节力矩 → [机械系统] → 关节角度 → [编码器] → 反馈
```

链条上每一环都有自己的动力学，时间尺度差得很远：电气环节（电流在电感里建立、磁场换相）在毫秒级以内，机械环节（带着减速器和连杆的转子改变转速）在几十到几百毫秒级，而干扰——摩擦、负载波动、电流纹波——各自从链条的不同位置钻进来。控制的任务是：无论这些干扰怎么捣乱，让链条末端的角度跟上指令。

最直接的想法是单个 PID：拿位置误差，直接算出电流指令。这个方案在纸面上成立，在物理上失败，失败的方式恰好暴露了正确的结构。

**第一个失败点：干扰的纠正路径太长。** 负载波动直接作用在转速上，摩擦直接作用在力矩上——它们进入链条的位置在"电流"和"机械"之间，而不在"位置"上。单环结构里，这些干扰要先穿过机械动力学，变成位置偏差，被编码器看见，控制器才开始纠正；纠正后的电流又要再穿过整条链，才能抵消干扰。一来一回，慢了一个数量级。问题的本质是：**干扰从中间进入，纠正却只能从两端绕行**。

**第二个失败点：一个增益伺候不了两个时间尺度。** PID 的增益决定了它对多快的偏差做出反应。电气环节需要控制器在毫秒级响应，否则电流纹波照单全收；机械环节却要求控制器别太快，否则机械尚未响应、纠正已经叠了好几层，增益稍高就振荡。一个环的带宽要同时压住毫秒级的电气问题和百毫秒级的机械问题，两个约束互相矛盾——调高了对机械有害，调低了放过了电气。

**第三个事实指出了出路：物理量本来就是分层可测的。** 电流有采样电阻或电流传感器，转速可以从编码器差分得到，位置就是编码器本身。链条上每个环节的输入和输出都测得到——这意味着链条的每一段都可以独立地围成一个反馈环。

把这三件事放在一起，结构就自己浮现了：**干扰从哪一层进入，就在哪一层设一个环把它吃掉**；每个环只面对自己那一段动力学，时间尺度冲突自然消解。这就是级联——不是为了结构好看，是因为物理本来分层，控制器应该贴着物理长。

## 2. 三个环，各自回答一个问题

沿指令的传播路径，三个环依次接管。每一环回答的问题不同，越靠内的问题越"物理"，越靠外的问题越"任务"。

**位置环回答"在哪里"。** 它拿轨迹规划器给出的期望位置与编码器反馈比较，输出一个速度（或力矩）指令。它不关心电流纹波、不关心摩擦——这些由内环处理，在它眼里整个内层系统就是一个"听话的执行器"：给指令，到位。

**速度环回答"转多快"。** 它把位置环给的速度指令与实测转速比较，输出电流指令。摩擦力矩、负载波动在这一层被就地抑制：它们刚一改变转速，速度误差立刻出现，纠正当场发生，位置环甚至察觉不到发生过干扰。这就是级联的第一个红利——**外环被内环隔离在干扰之外**。

**电流环回答"力矩对不对"。** 力矩正比于电流（$T = K_t i$，见[[电机原理]]），所以控制电流就是控制力矩。电流环工作在最高频率（ kHz 到几十 kHz ），把电流指令翻译成三相 PWM，同时吃掉供电波动、反电动势变化、开关纹波这些最快的干扰。它通常就住在[[FOC 与电流环]]的驱动器里，出厂即整定。

三个环嵌套起来，形成"指令逐层细化、干扰逐层就地消灭"的漏斗。这个漏斗能稳定工作，依赖一个前提，而这个前提是全部整定规则的源头。

## 3. 内环必须比外环快：带宽隔离的推导

位置环的工作方式是：把内环当作理想执行器——"我发 10 rad/s，它就是 10 rad/s"。这个假设在什么条件下成立？只有当内环的响应时间远小于位置环的反应周期时。设想位置环以 100 Hz 的节奏观察和纠正，如果速度环要 50 ms 才能到位，那么位置环发出指令后，看到的是"过时的执行结果"：它以为纠正不够，继续加码，而之前的纠正正在路上——几轮叠加，误差相位反了，纠正变成了激励，系统进入振荡。

这就是**带宽隔离原则**：内环带宽应至少是外环的 5–10 倍。数字来路很朴素——外环的纠正必须建立在内环"已经干完上一件事"的基础上，5–10 倍的时间余量让内环在外环眼里近似理想。三个环的带宽因此自然形成阶梯：电流环（ kHz 级）≫ 速度环（百 Hz 级）≫ 位置环（几十 Hz 级），恰好与链条上电气、机械的时间尺度对应——不是巧合，这正是第 1 节"贴着物理长"的落实。

带宽隔离原则反过来就是第一条诊断规则：**舵机高频抖动、异常发热，第一假设是环间耦合或内环带宽被激励到机械谐振**（谐振来自哪里，见第 7 节）。外环参数怎么调都压不住的振荡，病根多半在内环与机械的交界处。

## 4. 整定：从最内环开始，逐层向外

带宽隔离原则同时给出了整定顺序：**必须从电流环开始，电流环稳了再整速度环，最后整位置环**。逻辑与带宽隔离是同一条：整定外环时，内环必须已经表现得像一个理想执行器——否则外环整定面对的是"一个性格未知的执行器"，无论怎么调都是在补偿内环的毛病，内环以后一改，外环全部白调。

每一层的整定方法本身是一致的：先给 P，加到系统起振，回撤 30%；需要压超调就加 D；有稳态误差再加小 I。这个流程有效的原因也是分层的：**每层面对的被控对象 = 内环（已理想化）+ 该层自己的物理**，对象简单且特性明确，试错的搜索空间小。

各层失稳的"长相"不同，这是诊断信息：电流环失稳是最高频的啸叫与发热；速度环失稳是中频的嗡振；位置环失稳是低频的、肉眼看得到的来回摆动。听到抖动先辨频率，频率直接指向层级——这条规则在[[测试方法论]]的故障定位流程里是主干线索。

## 5. 反馈的天花板，与前馈

反馈有一个物理上无法绕过的天花板：**它只能在误差发生之后纠正**。误差不存在，反馈就没有输入——这意味着靠反馈跟踪一条加速轨迹，永远滞后半拍；靠反馈抵抗已知的重力，永远先塌下去一点。

出路是把"可以预测的部分"从反馈手里拿走，直接前馈注入。关节动力学里大量成分是可预测的：重力矩是位姿的确定函数，摩擦近似是速度的函数，惯性力是加速度乘惯量。这些量可以按当前状态实时算出来，直接加在力矩指令上——错误在发生之前就被抵消了，反馈只需要收拾剩余。

于是指令的结构变成：**前馈管你懂的，反馈管你不懂的**。前馈份额越高，反馈的负担越轻，跟踪越快越稳。但要警惕前馈的另一面：模型错了的前馈本身就是一个干扰源——重力模型偏了 10%，等于给系统加了 10% 的恒定推力，好在这些残余会表现为稳态误差，反馈仍然兜底。这就是为什么前馈和反馈必须配对使用：前馈求快，反馈保真。

## 6. 数字实现的纪律

上面的一切发生在连续时间假设下，落到数字控制器上，多出几条纪律，每条背后都是真实的失效模式。

**控制周期必须稳定。** PID 的微分项和离散差分对采样间隔极其敏感——周期抖动 10%，等效于给 D 项乘上一个随机数，表现就是莫名其妙的抖动。这就是控制任务对[[嵌入式与 RTOS]]实时性要求的物理来源：实时不是"快"，是"每次都在规定的时刻醒来"。

**速度反馈要么算得干净，要么别自己算。** 位置差分求速度在低速时会被量化噪声放大（两个几乎相同的编码器读数相减），正确做法是先滤波，或直接采用驱动器内部基于观测器的速度估计——舵机内部已经替你做了这一步。

**积分要防饱和。** 执行器饱和后（比如电流到顶），误差仍在累积，积分项越涨越大；等误差反向时，积分项要先"泄完"这些库存才能开始反向纠正，表现为严重的超调和恢复迟钝。抗饱和（anti-windup）就是在执行器饱和时冻结或回退积分——细节属于工程，但机理值得记住：**积分器是对"纠正一直没被执行"的记账，记账必须跟随真实执行情况**。

## 7. 环的外面：机械系统给控制画的上限

到目前为止视角都在环内。现在把视角拉到环外——控制再好，也不能好过被控对象允许的范围。三个机械事实为三环设定了天花板。

**谐振：传动系的刚度是有限的。** 减速器、联轴器、连杆都不是刚体，它们构成弹簧-质量系统，有一个固有频率。控制带宽一旦逼近谐振频率，环的纠正力会直接激励振荡——所以[[减速器]]的刚度决定了速度环带宽的物理上限，这也解释了为什么高刚性传动（如谐波减速器）是伺服品质的前提之一。

**背隙：换向时有一段空转。** 齿轮啮合的间隙让力矩换向时输出端短暂"失联"，位置环看到的是一段死区。死区里反馈断开，环会先冲过头再回头，表现为换向顿挫和极限环振荡。控制无法消除背隙（它发生在环外），只能靠机械预紧消除，或靠算法补偿。

**反射惯量：减速比选错，电机带不动也控不好。** 负载惯量折算到电机轴上要除以减速比的平方。折算惯量相对转子惯量过大时，电机的力矩大部分用于加减速负载，位置环增益怎么提都响应迟钝、容易振荡。惯量匹配是关节模组设计阶段就定死的事，控制器只能在既定匹配下工作。

这三条合起来给出一个系统级的结论：**舵机的性能是机械与控制共同设计的结果，控制环路的天花板在机械阶段就已经写好**。有了这个认识，舵机测试里看到的现象就不再是一堆孤立症状，而是物理透过闭环的显影：

| 现象 | 最可能的层级 | 机理 |
|------|------------|------|
| 高频抖动、异常发热 | 电流/速度环 | 带宽逼近传动谐振，或环间隔离被破坏 |
| 到位后低频振荡 | 位置环 | 增益过高，或折算惯量失配 |
| 跟踪滞后、爬行 | 速度环/前馈 | 带宽不足，或重力/摩擦前馈缺失 |
| 换向顿挫 | 机械（背隙） | 死区内反馈断开，环冲过头再回头 |
| 单向正常、反向超差 | 机械+位置环 | 背隙与摩擦换向的综合死区 |

这张表是[[测试方法论]]中"现象 → 层级 → 根因"定位逻辑的控制论基础。

## 8. 舵机：封装好的三环，与封装的代价

舵机（[[关节模组]]的最小形态）就是把上面的一切——三环控制、FOC、减速器、编码器——整包封装，对外只留一个位置指令接口。封装带来巨大的便利：上层不再需要理解任何控制细节。但便利的代价是黑盒：环参数不可调、内部状态不可见、性能上限在出厂时已定。

黑盒并非无事可做。封装之后仍然在你手里的变量有三个：**指令的频率与光滑度**（轨迹层的事，见[[DMP]]与轨迹生成）、**负载的设计**（惯量匹配是选型阶段的事）、以及**观察与测量**（舵机测试正是从端口侧探测封装内的物理）。本篇的第 7 节之所以重要，就在于它是"隔着一个黑盒做测试"时的唯一推理依据——现象在端口侧，根因在环内或环外，对应关系就是那张表。

## 9. 边界：这套结构什么时候不够用

级联 PID 隐含三个假设：每个关节独立、被控量是位置、关节与环境的交互可以忽略。三个假设破掉的场合，就是它的边界。

**强耦合动力学。** 多自由度机械臂的各个关节通过惯量张量和重力项互相耦合，"每个关节一个独立 PID"把耦合当作干扰硬扛——轻载低速时可以，高速高加速度时扛不住。出路是模型补偿（计算力矩控制）或整体求解（MPC）。

**交互任务。** 位置环的本性是"谁动我的位置我顶回去"——这在自由空间里是伺服刚性，在接触任务里就是灾难：机械臂按位置控制去擦工件，接触力完全不受控。力控必须换结构：阻抗控制把"位置响应"改为"力-位关系可编程"，这是控制栈的另一个分支。

**全身动力学。** 足式机器人的平衡是全身协调问题，关节级 PID 之上还必须有全身控制器（WBC）统一分配力矩——关节环退化为最内层的力矩执行。

注意这些边界不是 PID 的失败，而是假设的失效——在假设成立的范围内（单关节、位置任务、非接触），级联 PID 至今是性价比最高的答案。识别"我的问题还在不在假设内"，比记住任何具体参数都重要。

## 10. 收束：一个反复出现的模式

回头看，级联 PID 的全部内容可以压成一条抽象规则：**当系统由时间尺度悬殊的多层物理串联而成时，按层设环、内快外慢、干扰就地消灭**。

这条规则在机器人栈里到处重现：电流环内嵌于速度环、速度环内嵌于位置环是它；RTOS 里中断响应快于任务调度、任务快于后台逻辑是它；DDS 里数据分发给 QoS 分级（见[[DDS]]）也是同一思想在通信层的投影。认出这个模式之后，学习栈里任何一层都不再需要从零开始——问三个问题就够：这一层的干扰从哪进来、这一层的时间尺度是多少、它的内层是否已经足够快到可以被当作理想执行器。级联 PID 是这个模式最完整的范本，值得用它来校准自己对整个系统的直觉。

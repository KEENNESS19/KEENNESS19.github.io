# DMP 原理：从示教到可泛化的运动基元

> 决策层（状态机、行为树）回答"做什么"，运动生成层回答"怎么动"。DMP（Dynamic Movement Primitives, Ijspeert & Schaal, 2002 起）是这一层最经典的形式化：**把示教轨迹编码为一个动力学系统，让"复现"变成"演化"，让"泛化"变成"改变初始条件"**。本篇推导它的每个组件为什么必须存在。

---

## 1. 问题定义与候选方案的淘汰

需求拆开是四条：**复现**（忠实重演示教动作）、**泛化**（换目标位置/速度时自动生成新轨迹）、**鲁棒**（扰动后能回到轨迹上）、**在线**（不需要重优化就能改）。

### 1.1 为什么不用轨迹重放

把示教记录成时间戳序列直接回放：复现满分，但三条全挂——换目标只能靠坐标变换（姿态和避障下的路径形状不会跟着变）；扰动后"时间还在走"，轨迹与现实脱节；无法在线调整。根因：**重放把运动绑定在时间轴上**。

### 1.2 为什么不用在线轨迹优化

每改一次目标就解一次优化问题：泛化好，但毫秒级控制循环里跑优化不现实，且优化结果对代价函数设计敏感。根因：**把"生成轨迹"建成了搜索问题而非演化问题**。

### 1.3 DMP 的思路转向

DMP 把问题反过来：**不存储轨迹，存储一个能"产生"这类轨迹的动力学系统**。示教只用来估计系统的参数；执行就是让系统从初态演化到目标。复现 = 演化本身，泛化 = 改演化系统的参数（目标点），鲁棒 = 动力学系统的吸引子性质（被推离后自动回来），在线 = 演化随时可继续。一次建模，四条需求同时满足——这就是为什么值得引入下面这套略显繁复的公式体系。

## 2. 结构：三个组件各回答一个问题

DMP 由三个耦合的微分方程组成，每个组件的存在理由单独成立：

### 2.1 规范系统（canonical system）：为什么用相位替代时间

$$\tau \dot{s} = -\alpha_s s, \qquad s(0)=1$$

一个从 1 指数衰减到 0 的标量相位 s。**为什么不让强迫项直接依赖时间 t？** 因为 t 是"墙钟"，s 是"运动进度"：

- **时间不变性**：执行中被打断/暂停（暂停 τ 积分），恢复后从当前相位继续——运动"知道自己走到哪了"，而依赖 t 的系统暂停后必须快进补时间；
- **速度调整**：改 τ（时间常数）整条轨迹等比加减速，无需重学；
- 相位衰减到 0 后强迫项自动归零——系统"内置了结束"。

这是 DMP 最关键的设计决策：**把时间从自变量变成状态变量**，重放方案的全部病根（绑定墙钟）在此消除。

### 2.2 变换系统（transformation system）：为什么基线是弹簧阻尼

单自由度情形（位置 x，速度 v）：

$$\tau \dot{v} = \alpha_z\big(\beta_z (g - x) - v\big) + f(s), \qquad \tau \dot{x} = v$$

$f=0$ 时这是一个临界阻尼弹簧-阻尼系统：从任意初值**指数收敛到目标 g**——收敛性有解析保证，不依赖学习。**为什么要先有这个稳定基线？** 因为学习组件（2.3）引入的项必须"叠加在稳定之上"：即使强迫项学坏了、截断了，系统最坏退化为"直线收敛到目标"，不会发散。**稳定性和灵活性被分到两个组件，各负其责**——这是控制论里"反馈保证稳定、前馈塑造形状"思想的教科书实现。

### 2.3 强迫项（forcing term）：学习的到底是什么

$$f(s) = \frac{\sum_{i} w_i\,\psi_i(s)}{\sum_i \psi_i(s)}\, s\,(g - x_0)$$

高斯基 $\psi_i(s)$ 铺在相位轴上，权重 $w_i$ 即"学到的轨迹形状"。**为什么乘 $s(g-x_0)$ 这两项？**

- 乘 $s$：相位归零时强迫项归零——保证终段永远由弹簧阻尼接管，收敛性不被学习项破坏；
- 乘 $(g-x_0)$：**空间缩放因子**——目标从 g 换到 g' 时，整条形状按位移比例自动伸缩，**同一个 $w_i$ 服务所有目标**。这就是"泛化"在公式里的位置：不是额外机制，是一个乘法因子。

**权重怎么学？** 示教轨迹 $\{x_{demo}, \dot{x}_{demo}, \ddot{x}_{demo}\}$ 反解出每个时刻的"应加强迫项" $f_{target}(t)$，再对它做加权线性回归（LWR）拟合高斯基权重——每个基一个标量最小二乘，**无迭代优化、无局部极小**。学习的廉价性是 DMP 工程可用的关键。

## 3. 泛化行为的完整清单

有了上面的结构，DMP 的"免费泛化能力"可以逐条列出：

- **换目标位置**：改 g，弹簧吸引子移动，形状按 $(g-x_0)$ 缩放——抓桌上不同位置物体；
- **中改目标（在线重规划）**：g 可在执行中更新（但要小心 hitchhiking：目标突变时轨迹可能被"劫持"绕远路，因为强迫项还带着旧目标的缩放——工程上用渐进更新 g 或中断重启）；
- **加减速**：调 τ；
- **中途扰动**：推一下机械臂，弹簧阻尼把它拉回强迫项塑造的路径——**鲁棒性是吸引子性质，不是重规划**。

局限同样从公式读出：强迫项只学"目标向的位移形状"，**不会自主避障**（形状随目标缩放，但障碍不在模型里）；解决靠耦合项（4.2）或换更富表达力的框架。

## 4. 扩展与生态

### 4.1 笛卡尔 DMP：姿态怎么办

位置是 3 维 DMP 并联即可；姿态的四元数部分（见[[四元数]]）没有加法群结构——$g - x$ 无定义。解法：用四元数的指数/对数映射定义"姿态差"，让 DMP 演化在切空间上进行（Ude et al., 2014）。这是"李群上做动力学"的标准操作，与四元数篇 5.2 的 ESKF 是同一思想：**全局用流形量，误差/增量用切空间量**。

### 4.2 耦合项与避障

在变换方程外加耦合项：避障力场（Ozcelik & Billard 的 obstacle avoidance coupling term 把障碍斥力注入 $\dot v$）、力/阻抗耦合（与人协作时的柔顺）。耦合项的设计同样遵守 2.2 的原则——**加项不破坏收敛结构**。

### 4.3 与 ProMP 的对比：确定 vs 概率

ProMP（ProMP, Paraschos et al. 2013）把轨迹建模为高斯过程式的概率分布，输出的是"轨迹的均值 + 协方差"。选型逻辑：

- **DMP**：确定性、有目标吸引子、改目标自然、适合"有一个明确意图"的动作（抓取、插孔）；
- **ProMP**：带不确定性、可做轨迹级协方差调制（条件在 waypoint 上）、适合多解动作建模（人的风格差异）；
- 共同点是"相位替代时间"的规范系统思想——**DMP 的真正遗产是这个骨架，而不只是公式**。

### 4.4 在架构中的位置

衔接决策篇的分层（状态机篇 7、行为树篇 8）：行为树叶子节点"抓取"的执行体就是一组 DMP——BT 决定**何时**调用哪个基元，DMP 负责**怎么动**以及被扰动后**如何恢复**。DMP 不做决策（它没有条件分支），BT 不做运动（它没有动力学）——两者的接口是"启动/中止/改目标"三个调用。

## 5. 结语

DMP 的推导链：**需求四条（复现/泛化/鲁棒/在线）→ 重放绑时间、优化太贵 → 转向"存储动力学系统" → 相位替代时间（时间不变性）→ 弹簧阻尼保底（收敛不依赖学习）→ 高斯强迫项学形状（$s$ 保稳定、$g-x_0$ 保泛化）→ 学习退化为逐基线性回归 → 换目标/加减速/抗扰全是"改初始条件"**。理解了"$s$ 和 $(g-x_0)$ 两个乘法因子各自买了什么"，DMP 就不是一组要抄的公式，而是"把轨迹变成吸引子"这一个想法的完整实现。

# 编码器

**一句话定义：编码器 = 把机械角度转换为电信号的传感器；控制环、标定、测试里所有"位置"一词的可信度都来自它。**

## 内核：为什么分增量式与绝对式

位置反馈有个根本分野：**断电重启后，零位还在不在？**

- **增量式**：码盘均匀刻线，转一圈输出 N 个脉冲 + 一条零位脉冲。控制器**数脉冲**得知相对位移——便宜、分辨率高，但断电即失忆，上电必须找零；丢一个脉冲（抖动/干扰）误差永久累积。
- **绝对式**：每个角度位置对应唯一码值（单圈）或唯一计数（多圈，电池/机械记圈）——上电即知位置，没有累积误差，代价是码盘复杂、价格高。

由此推出一个容易记混的概念区分：**分辨率 ≠ 精度**。分辨率是能分辨的最小刻度（多少线/多少位），精度是读数与真实角度的偏差（受码盘安装偏心、细分误差影响）。标定算法再好，也超不过编码器精度这条天花板。

## 规则与行为

**四倍频**：增量式 A/B 两相正交（相差 90°），比较相位即知方向；对 A、B 的上升沿与下降沿都计数，分辨率 ×4——这是"2000 线编码器输出 8000 计数/圈"的来源。

**选型与使用规则**：

1. **控制环位置**：电流环内不需要编码器（FOC 换相用的角度可低分辨率甚至无感估计），速度环用增量即可，**位置环与安全相关处必须绝对式**——机械臂断电不下坠、重启不需要找零，靠的就是多圈绝对值编码器。
2. **双编码器方案**：关节模组常在电机端与输出端各放一个（后者在[[减速器]]之后）。输出端编码器看到的是"真实关节角"（含背隙与柔轮形变），电机端看到的是"转子角"（换相必需、带宽高）。**两者之差直接度量传动链误差**——舵机测试里对比这两个读数是最有诊断价值的手段之一。
3. **时间戳纪律**：编码器读数必须带采集时刻（见[[数据回放与时间同步]]），位置环里用错时间戳的读数等效于引入速度噪声。

## 抽象："真值"角色

抽象后，编码器在系统里扮演三个角色：**控制环的反馈**、**标定的基准**（[[传感器标定]]里手眼标定的 AX、XB 都由它驱动）、**测试的裁判**（指标里的"到位精度"以它为准）。一个务实的推论：**做任何"精度"实验前，先问编码器的精度与安装方式**——真值链上端的误差无法被下端修复。

# FOC 与电流环

**一句话定义：FOC（磁场定向控制）= 用随转子旋转的 dq 坐标系分解三相电流，让"产生力矩的分量"（q 轴）与"产生磁场的分量"（d 轴）解耦，从而把力矩控制变成对一个电流值的控制。**

## 内核：为什么三相电流不够用

从[[电机原理]]知道 $T = K_t i$，但那是对"与磁场垂直的等效电流"说的。三相定子电流是三个随时间正弦变化的量，直接控制它们等于控制三个耦合的旋转向量投影——**你想要的力矩和它们的关系随转子角度变**，控制律写不出来。

FOC 的内核动作只有一步：**把坐标系搬到转子上**。Clarke 变换（三相 → 两相静止 αβ）+ Park 变换（静止 → 随转子转的 dq）之后：

- **q 轴电流 $i_q$**：与转子磁场垂直 → 唯一产生有效力矩（$T = 1.5\,p\,\psi\,i_q$，$\psi$ 是磁链）；
- **d 轴电流 $i_d$**：与转子磁场同向 → 不产生力矩，只发热（表贴式电机令 $i_d = 0$）。

**在旋转坐标系里，正弦量变成了直流量**——控制直流量是经典 PI 的舒适区。这就是"旋转坐标系"这个动作的全部收益。

## 规则与行为

**三环级联的最内环**（完整结构见[[级联 PID]]）：

```
位置环 → 速度环 → 电流环(FOC) → PWM/SVPWM → 逆变器 → 电机
```

使用规则四条：

1. **电流环必须最快**（带宽几十 kHz 级、周期微秒级）：它是内环的地基，且 PI 参数在 dq 系里有解析解（由电阻电感定），通常驱动器已整定好。
2. **SVPWM 是执行端**：逆 Park 得到的三个电压指令如何变成 PWM 占空比——空间矢量调制比正弦调制多榨出约 15% 母线电压利用率，是"免费的"优化，理解层面知道即可。
3. **换相需要转子角度**：FOC 每个周期都要真实转子角（编码器或无感估计）。角度误差直接变成力矩误差和效率损失——[[编码器]]的精度在这里兑现。
4. **弱磁是 d 轴的第二个用途**：高速时反电动势逼近母线电压上限，给 d 轴负电流"削弱磁场"换取转速上限——代价是力矩常数下降。机器人关节低速运行通常用不到。

## 抽象：力矩源接口

FOC 对上层的全部意义压缩成一个接口：**设 $i_q$ = 设力矩**（误差来自 $K_t$ 的温度漂移与谐波）。有了它：

- 速度环输出 $i_q$ 指令（速度环=力矩环的外环）；
- 力控机器人直接在 $i_q$ 上做文章（配合关节力矩传感器校准）；
- 测试里"堵转电流异常""电流环振荡"这些现象，定位顺序是：先查 $K_t$ 与相电阻漂移，再查编码器角度。

# 卡尔曼滤波应用：EKF 传感器融合实战

**一句话定义：EKF 融合 = 把多传感器的互补性写成"状态 + 过程模型 + 观测模型"三件套，让[[卡尔曼滤波]]的五公式按协方差自动分配信任。**

## 内核：从互补滤波到状态空间

[[IMU 姿态解算]]的互补滤波把信任比例写死在增益里；EKF 的升级在于**让状态概念显式化**：被估计的不只是姿态，还包括"所有会漂的东西"——陀螺零偏、编码器刻度、传感器间的时延。**把误差源抬进状态向量，是融合系统与滤波玩具的分水岭**：漂移从"不可控的退化"变成"被持续观测和补偿的量"。

三件套怎么填（以 IMU + 编码器里程计融合位姿为例）：

1. **状态向量**：位置、速度、姿态（流形量，见下）、陀螺/加计零偏。
2. **过程模型**：IMU 读数驱动状态演化——IMU 从"传感器"变成"过程输入"，这正是 IMU 频率可以很高的原因。
3. **观测模型**：其他传感器（里程计、GPS、磁力计）作为低频观测修正漂移。

## 规则与行为

**姿态是流形，正规做法是误差状态 EKF（ESKF）**：名义状态用四元数积分，误差定义在切空间的三维小向量（[[李群李代数]]的扰动模型），误差协方差在切空间传播，更新后把修正量注回名义状态再归一化。**为什么不能直接对四元数做 EKF**：四元数带单位约束，4 维高斯与约束流形不兼容；误差在切空间里永远是小量，线性化合法。

**调参规则**（理论依据见数学篇"分配信任"）：

1. Q 矩阵来自器件数据手册的噪声密度 + 模型简化误差——**先查手册再调参**；
2. R 来自静态数据统计（器件静止时的读数方差，顺手完成零偏初估）；
3. 融合结果震荡 → R 太小；跟踪迟滞 → R 太大或 Q 太小。

**一致性检验**（晦涩处，展开）：滤波器自报的协方差 P 与实际误差是否相符，可用 NIS（归新息平方）检验——新息 $z - H\hat{x}^-$ 的加权值应服从卡方分布。**NIS 长期超标 = 滤波器在说谎**（模型失配或 R/Q 错），此时估计值和 P 都不可信。这是判断"融合结果能不能用于闭环控制"的客观依据。

**时间戳纪律**：观测模型隐含"读数对应哪个时刻的状态"。传感器间时延差几毫秒，高速运动下就是厘米级误差——对齐时间戳（外推或时延入状态）在融合里不是工程细节而是正确性条件（见[[数据回放与时间同步]]）。

## 抽象：ESKF 是个可复用模板

抽象后的融合开发只剩填空：**状态向量 + 两个模型 + 初始 Q/R**。IMU+轮速计、IMU+GPS、IMU+视觉里程计，模板同一。写代码时的落点：开源实现（robot_localization 的 ekf_localization_node、VINS 的 ESKF）都长这个骨架——读它们前先读本篇，你会看到的是熟悉的三件套而不是陌生的公式堆。

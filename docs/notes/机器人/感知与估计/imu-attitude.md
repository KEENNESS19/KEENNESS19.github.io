# IMU 姿态解算

**一句话定义：姿态解算 = 让"短期可信"的陀螺积分与"长期可信"的重力/磁场观测互为校准，得到既平滑又不漂的姿态。**

## 内核：为什么单个传感器都不行

IMU 两颗核心器件的误差性质恰好**互补**（器件层误差模型见硬件篇的 IMU 小节）：

- **陀螺仪**：输出角速度。积分得姿态——高频响应好、平滑；但零偏被积分放大，姿态**随时间漂移**（每秒零点几度，一小时后不可用）。
- **加速度计**：静止时测到重力方向 → 提供"水平姿态"（roll/pitch）的绝对参考——不漂；但任何运动加速度都会混入读数，**瞬时噪声大**。且它无法观测绕重力轴的偏航（yaw）——重力对 yaw 无向性，必须加磁力计补（磁力计又受电机磁场干扰，这是 yaw 永远最弱的原因）。

**互补的直觉**：陀螺走高频、加计走低频——高通滤波陀螺 + 低通滤波加计，再相加。这一个频段分工就是所有姿态融合算法的共同内核。

## 规则与行为

**Mahony/Madgwick 滤波**（工程标配）的实现只有三步，本质是一个 PI 反馈：

1. 用当前姿态估计预测"重力应该指向哪"；
2. 与加计实测的重力方向做叉积 → 得到姿态误差（一个旋转校正向量）；
3. 误差经 PI 增益（P 消瞬时误差，I 顺便估计陀螺零偏）注入陀螺角速度，积分更新姿态。

用[[四元数]]做姿态载体（避免奇异、插值方便、微分方程有 ½ 因子），十几行代码即可跑通。**调参规则**：P 大 = 姿态跟重力紧（抖）、P 小 = 跟陀螺紧（漂）；I 的积分值就是在线估计的陀螺零偏——**I 通道的价值不只是消稳态误差，而是把器件误差模型里的零偏项活学活用**。

**它与卡尔曼滤波的关系**：互补滤波 = 把"高频信陀螺、低信加计"写死在增益里的简化版；KF 版（见下一应用篇）则让增益由协方差动态计算，并顺带估计零偏等状态。两步走的学习路径：先手写 Mahony 理解分工，再上 EKF 理解形式化。

## 抽象：AHRS 模块

抽象后的姿态解算是一个标准模块：**输入 IMU 原始数据（带时间戳），输出姿态四元数（带频率与置信度）**——即 AHRS（航姿参考系统）。ROS 生态里 `imu_filter_madgwick` / `complementary_filter` 都是现成实现。理解了内核，你可以在三个层次复用：直接用模块、改增益适配器件、或升级成 ESKF（[[李群李代数]]的扰动模型 + [[卡尔曼滤波]]的五公式）。yaw 的短板是模块边界——需要绝对 yaw 时，解法只有磁力计融合或外部定位，没有第四条路。

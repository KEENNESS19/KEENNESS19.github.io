# 传感器标定

**一句话定义：标定 = 估计传感器的固有参数（内参）与安装位姿（外参），使多源数据在统一坐标系下自洽。**

## 内核：为什么标定是绕不开的

每个传感器出厂自带**自己的坐标系**：相机系原点在光心，IMU 系在芯片的某只引脚旁，激光系在转镜中心。它们被拧到机器人上时，又叠加一个**随手的安装位姿**。而所有上层算法（融合、避障、抓取）都默认"数据在世界系/机体系下对齐"——

**不对齐的根源有两类，标定就分两半**：

- **内参**（器件固有、与安装无关）：相机焦距/畸变、IMU 的刻度因子/零偏/轴间非正交、编码器的零位偏移。它们是器件"自己的性格"，由出厂工艺误差决定。
- **外参**（安装位姿）：传感器系到机器人系的旋转平移 $T$（[[坐标变换与齐次矩阵]]的 $T_{AB}$ 就是它的容器）。

**标定的统一形式是一个优化问题**：给参数赋初值 → 构造残差（"如果参数是对的，这些观测量本应相等"）→ 最小二乘迭代（Gauss-Newton / Levenberg-Marquardt）。不同标定算法只是换了残差定义。

## 规则与行为

**手眼标定（最经典的外参标定，展开说）**：相机装在机械臂上，要估相机-末端变换 $X$。机械臂动两次，世界系下有恒等式：

$$A X = X B$$

其中 A 是两次末端位姿之差（机械臂自己知道），B 是两次相机观测之差（标定板给出）。几何意义：**末端与相机一起动，它们的相对位姿 $X$ 不变**——用"变化的组合"把"不变的量"解出来。AX=XB 的求解要求旋转轴方向多样，由此得到第一条实践纪律：

**激励充分性规则**：标定数据必须覆盖足够多样的姿态/视角（旋转轴不能共线）。数据平庸，解就平庸——90% 的标定失败是数据问题而不是算法问题。

**规则清单**：

1. **先内参后外参**：内参错则外参必然跟着错（残差被外参吸收）。
2. **标定要闭环验证**：标完用未参与标定的数据检查残差/重投影误差；机械臂场景用"指到点上"的末端重复性验证。
3. **温漂与振动会破坏标定**：外参是"当天有效"的量，碰撞后重标。长期运行的大系统把标定做成例行流程（见[[整机联调流程]]）。
4. **零位偏移是外参的特殊情形**：关节编码器零位偏移标定 = 把"关节读数"与"外部真值"（限位/标定块/目视）对齐——舵机测试里"零位不对"本质是这一条。

## 抽象：TF 树是外参的容器，标定是它的填充器

外参的抽象归宿是 TF 树：每个传感器在树上有唯一位置，标定算法产出的 $T$ 写入树中（见[[TF 树]]）。于是"标定"在架构里变成一个**纯数据生产者**——产出带不确定度的时间戳化外参。这个抽象让标定从"一次性仪式"变成"可维护的数据"：谁变了（换相机、碰撞）就重产谁，上层算法无感知。

# 减速器

**一句话定义：减速器 = 用转速换力矩的功率变换器——理想下功率不变，扭矩放大 n 倍，转速降低 n 倍。**

## 内核：为什么必须有它

电机天然"高速低扭"（小型无刷的最高效率点在几千转），负载天然"低速大扭"（关节每秒转不过一圈却要几十牛米）。直驱方案要求电机**直接输出大扭矩**，意味着巨大的体积重量与惯量。减速器用一组齿轮完成交换，代价写进物理定律：

1. **效率损失**：$\eta$ 典型 0.75–0.95，发热由此而来；
2. **反射惯量平方定律**：折算到电机轴的负载惯量 = 负载惯量 / n²。这条定律是双刃剑——大减速比让电机"感觉负载很轻"，控制容易；但也让碰撞时电机难以察觉，力控的透明性变差（力控篇会回来收这个伏笔）。

**背隙**（齿与齿之间的空程）与**刚度**（扭转形变）是减速器仅有的两个"性格参数"，下面所有选型差异都从它们出发。

## 规则与行为

三类主流方案的差异全部来自实现结构：

| 方案 | 结构 | 背隙 | 刚度 | 适用 |
|------|------|------|------|------|
| 行星齿轮 | 多个行星轮分担载荷 | 小（非零） | 高 | 通用、便宜、大批量 |
| RV 减速器 | 行星前级 + 摆线针轮后级 | 极小 | 很高 | 中大负载工业关节 |
| 谐波减速器 | 柔轮受控变形啮合 | **几乎为零** | 较低（柔轮会扭） | 轻负载、高位置精度 |

由此推出四条选型与使用规则：

1. **减速比选择**：先按负载力矩留 2 倍裕度定理论比，再用**惯量匹配**校验——反射后负载惯量与转子惯量之比建议 < 10（比值越大，控制越"软"，表现为超调与振荡）。这条直接解释舵机测试里"换大负载后开始抖"的现象。
2. **背隙的后果**：换向死区。位置环里表现为反向时的"空走"，闭合回路里表现为极限环振荡。需要频繁换向的关节（腕部）优先零背隙方案。
3. **刚度的后果**：谐振。传动链刚度与惯量构成弹性系统，谐振频率以下的控制带宽才安全——**刚度越低，可用的控制带宽越低**。谐波的柔性是它换零背隙的账单。
4. **润滑与寿命**：谐波柔轮疲劳是有限寿命件（按转数计），选型时查寿命曲线而不是只看额定扭矩。

## 抽象：关节模组把传动问题封装掉

"电机 + 减速器 + 双编码器 + 驱动器 + 力矩传感器"集成一体 = **关节模组**。它的意义是把"选电机、选减速比、配编码器、调电流环"整包封装成几个选型参数（额定扭矩/减速比/通信接口）。[[级联 PID]]篇会说明：模组内部已实现三环，你拿到的只是位置指令接口——**理解本文的背隙与刚度，是为了在模组行为异常时知道该怀疑哪一层**。

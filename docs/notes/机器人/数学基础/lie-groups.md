# 李群与李代数

**一句话定义：李群是"既是群又是光滑空间"的集合（SO(3) 旋转、SE(3) 位姿）；李代数是它在单位元处的切空间——弯曲空间上唯一的线性区域。**

## 内核：为什么需要它

已有两个事实：旋转是弯曲空间（[[四元数]]篇）；工程运算却大量需要**加法结构**——求两个姿态的平均、加一个扰动、算一个误差、做高斯滤波。线性运算在弯曲空间上没有定义，$q_1 + q_2$ 不是合法姿态。

矛盾的解法藏在微分几何里：**流形在每一点都有一个切空间，切空间是平的线性空间**。单位元处的切空间叫李代数（so(3) 是三维角速度向量，se(3) 是六维 twist）。连接两者的是**指数映射**：

$$\exp:\ \mathfrak{so}(3) \to SO(3), \qquad \exp(\boldsymbol{\phi}) = \text{绕轴 } \hat{\phi} \text{ 转 } \|\phi\| \text{ 角的旋转}$$

指数映射把"一个小旋转向量"变成"一个真实旋转"，对数映射反向。**于是弯曲空间上的所有线性需求，都搬到切空间完成，再用 exp 送回去。**

## 规则与行为

**扰动模型**（最高频的用法）：真实姿态 $R$ 受小扰动 $\delta\phi$ 时，不写 $R + \delta$（非法），而写左扰动 $R \gets \exp(\delta\phi^\wedge)\,R$ 或右扰动 $R \gets R\,\exp(\delta\phi^\wedge)$。左右之别即"扰动挂世界系还是机体系"（与[[坐标变换与齐次矩阵]]的左右乘规则同构）。

**误差定义规则**：姿态误差 = $\log(R_{ref}^\top R)^\vee$，一个三维小旋转向量。它可加权、可滤波、可求导——ESKF（[[四元数]]篇 5.2）里的"误差状态"正是它。

**优化规则**：流形上的最小二乘，每次迭代在切空间求增量 $\delta$，更新走 $R \gets \exp(\delta^\wedge) R$ 再归一回流形。g2o / Ceres / GTSAM 全部是这个模式——所以李代数是读懂 SLAM 后端与标定优化器的门票。

**为什么"小量"没有奇异**：拓扑定理只禁止"全局无奇异的三参数化"；切空间坐标只描述单位元附近的局部，永远停留在线性区，小量假设天然满足（[[四元数]]篇 5.2 的结论）。

## 抽象：一个模式替代一堆技巧

没有李代数时，旋转平均、姿态误差、不确定性传播各自要 ad-hoc 处理；有了它，收敛成一个统一模式：

**全局表示用流形量（四元数/矩阵），一切线性运算在切空间，exp/log 负责往返。**

积分（$\dot R = R\,\omega^\wedge$ 的解）、误差（log）、平均（切空间加权再 exp）、滤波（ESKF）全是该模式的实例。后续的 IMU 解算、标定、SLAM 文章遇到"为什么误差是三维向量"时，答案都在这里。

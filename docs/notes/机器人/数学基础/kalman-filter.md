# 卡尔曼滤波理论

**一句话定义：卡尔曼滤波 = 在"模型预测"与"传感器观测"都有噪声时，按各自协方差（可信度）做最优加权融合的递推算法。**

## 内核：为什么需要它

估计一个状态（如姿态、位置）有两条信息来源，各有缺陷：

- **模型预测**：用上一时刻状态按物理规律外推——平滑但**漂移**（误差随时间累积）；
- **传感器观测**：直接测量——不漂但**噪声大**（单次读数抖）。

两者的误差性质互补：预测误差慢变、观测误差快变。**最优策略不是二选一，而是按可信度加权平均**——协方差小的权重高。这一句就是全部直觉，五个公式都是它的代数化。

**为什么"最优"可证**：在"线性模型 + 高斯噪声"假设下，后验分布仍是高斯，加权平均恰好等于 Bayes 后验均值——KF 是那个线性高斯世界的 Bayes 最优解。两条假设各自松动时的对策见下文 EKF/UKF。

## 规则与行为

递推结构只有两步，每步一个"均值 + 协方差"：

**预测**（相信模型）：

$$\hat{x}^- = F\hat{x}, \qquad P^- = FPF^\top + Q$$

**更新**（相信观测，按可信度加权）：

$$K = P^-(H^\top)(HP^-H^\top + R)^{-1}, \qquad \hat{x} = \hat{x}^- + K(z - H\hat{x}^-), \qquad P = (I-KH)P^-$$

从公式读出四条使用规则：

1. **Q 与 R 的比值就是"信模型还是信传感器"**。调参不是玄学：Q 大 = 承认模型差（更信观测）；R 大 = 承认传感器差（更信模型）。滤波器震荡过猛 → R 调大或 Q 调小；跟随过慢 → 反之。
2. **协方差 P 是"不确定性账户"**：预测使它变大（$+Q$），观测使它变小。P 发散说明账户透支——模型与真实过程失配。
3. **卡尔曼增益 K 自动权衡**：观测噪声突然变大（R 有效变大）时 K 自动变小——融合是逐时刻自适应的，不需要人干预。
4. **非线性怎么办**：真实系统几乎都非线性。EKF 把非线性函数在当前点**泰勒展开取一阶**（雅可比代替 F/H），工作点是移动的所以每步重算；UKF 不求导，用确定性采样点穿过非线性函数统计均值协方差。选择规则：弱非线性、状态量小用 EKF；强非线性或雅可比难写用 UKF。姿态这种**流形状态**的正规做法是误差状态 EKF（[[李群李代数]]的扰动模型），见感知篇的融合实战。

## 抽象：所有"融合"问题的统一模板

KF 的真正威力是它把一类问题**模板化**：任何多传感器融合，只需回答三个问题——

1. 状态向量选什么（要估计什么）？
2. 过程模型怎么写（状态怎么随物理规律演化）？
3. 观测模型怎么写（每个传感器怎么由状态算出读数）？

写完两个模型，剩下交给五公式。IMU 融合、定位、目标跟踪全是同一模板的填空——应用层的展开见感知篇。本篇只负责一件事：**让你确信"调参 = 分配信任"以及"模型错了 P 一定会告诉你"**。
